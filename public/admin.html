Referral rewards

The invited user must finish a number of different tasks before the inviter is paid.

04

Mining

Set the reward earned per hour and the length of each mining session.

Mining payout is calculated as reward per hour × session duration. Active sessions keep the rate and duration saved when they started.
05

Ads & AdsGram INT

Use a separate block for automatic ads and one shared block for tasks, exchange, withdrawals and mining.

Automatic ads use only the Automatic block and never grant rewards. Tasks, exchange, withdrawals and mining use only the Reward / action block. A no-fill response is retried.
06

AdsGram Native Task

Show a native AdsGram task popup after the user's third tap. Leave the block ID empty to disable it.

Use one AdsGram Task block in the AdsGram platform. The server grants this reward only after AdsGram calls the configured Reward URL. The popup appears once per app session after 3 taps and can be closed.
07

Arcade & daily rewards

Set daily game attempts, minimum server play time and the fixed reward for each successful mini-game.

07A

Seven-day check-in rewards

Set the Coin reward for each day in the daily streak cycle.

Attempts are shared across all five games. A started run consumes one attempt, including if the player exits early. Each verified AdsGram reward ad grants one extra attempt, up to the daily cap. Set a game reward to 0 to disable it. Daily rewards restart at Day 1 after a missed day.
